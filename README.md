# Octagon Spire: Championship Path

A Godot 4-based MMA deck-building roguelike inspired by Slay the Spire, built on the robust [Slay the Robot framework](https://github.com/DesirePathGames/Slay-The-Robot).

## 🥊 Game Concept

Fight your way from amateur regional circuits to the Ultimate Fighting Championship! Each run represents a fighter's journey through three distinct leagues:

### 🏟️ **Act I: Regional Circuit**
- Face local amateur fighters
- Learn basic striking and grappling techniques
- Build your foundation deck

### 🏆 **Act II: National Championships** 
- Battle seasoned professionals
- Master advanced combinations
- Face fighters with specialized styles (strikers, grapplers, etc.)

### 🌟 **Act III: Ultimate Fighting Championship**
- Challenge elite champions
- Execute complex fight strategies
- Earn your place among the greatest fighters

## 🎮 Core Mechanics

### **Position-Based Combat**
- **Standing**: Striking, clinch work, takedown attempts
- **Ground**: Ground & pound, submissions, escapes
- **Transitions**: Dynamic position changes during fights

### **Card Categories**
- **🥊 Strikes**: Jabs, hooks, kicks, elbows
- **🤼 Grappling**: Takedowns, submissions, ground control
- **🛡️ Defense**: Blocks, dodges, counters
- **⚡ Conditioning**: Stamina, recovery, mental focus
- **🎯 Strategy**: Fight IQ, timing, combinations

### **Fighter Progression**
- Unlock new techniques after victories
- Train with different coaches (artifacts)
- Develop your unique fighting style
- Face opponents with distinct AI patterns

## 🛠️ Technical Foundation

Built on the **Slay the Robot** framework, featuring:
- **Data-driven card system** with JSON configuration
- **Robust action system** for complex interactions  
- **Modular status effects** for conditions and buffs
- **3-act progression** with branching paths
- **Save/load system** with run persistence
- **Mod support** for community content
